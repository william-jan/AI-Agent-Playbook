# ImageGen pada Codex

**Status:** konsep didukung dokumentasi resmi; ketersediaan di VS Code **perlu diperiksa pada sesi pengguna**.

- **`imagegen`** adalah Agent Skill: panduan workflow pembuatan/editing gambar raster.
- **`image_gen`** adalah tool: kemampuan yang benar-benar menghasilkan/mengedit gambar.

## Kenapa hasilnya malah CSS?

Karena Codex adalah coding agent; jika image tool tidak tersedia, skill tidak dipanggil, atau instruksi kurang spesifik, agent mungkin memilih solusi berbasis kode. Untuk artwork game, tegaskan kebutuhan **raster image generated by AI**, bukan placeholder CSS/SVG.

## Generate

> Buat ninja very-high-detail pixel art, full body, PNG transparan. Simpan hasil di `public/assets/characters/ninja.png`. Gunakan generator gambar AI, bukan CSS/SVG/HTML Canvas atau Python sebagai pengganti artist. Jika tool tidak tersedia, laporkan, jangan buat placeholder.

## Edit anomali tanpa mengulang total

> Edit sprite yang saya berikan; perbaiki **hanya** anatomi tangan kanan. Pertahankan identitas, pose lain, outfit, warna, shading dan outline. Simpan non-destruktif sebagai file baru. Periksa hasilnya.

## Batasan nyata

- Generate ulang dan editing sama-sama bisa mengubah bagian yang seharusnya tetap.
- Sprite sheet 8×8 tidak dijamin tepat 64 karakter oleh prompt; validasi frame programatis.
- Background checkerboard tergambar **bukan** transparansi; uji alpha channel.
- Mode built-in adalah default menurut sample resmi. CLI/API fallback dapat membutuhkan `OPENAI_API_KEY` dan biaya; jangan pakai tanpa izin.
- Untuk edit file lokal, panduan resmi menjelaskan pemeriksaan dengan tool view image agar gambar dapat dijadikan konteks.
