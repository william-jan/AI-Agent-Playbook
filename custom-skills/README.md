# Custom Skills

Belum ada custom skill executable di sini. Folder ini menyimpan ide dan catatan rancangan, agar tidak menyamakan contoh dengan tool yang sudah teruji.

## Ide: kagefall-sprite-repair

```text
kagefall-sprite-repair/
  SKILL.md
  scripts/
    validate_grid.py
    inspect_alpha.py
  references/
    style-guide.md
```

Alur: input reference → image generation/editing tool bila tersedia → validasi ukuran/grid/alpha dengan scripts → screenshot gameplay → laporan kualitas.

Skill ini tidak menciptakan generator gambar dan tetap memerlukan tool yang sesuai.
